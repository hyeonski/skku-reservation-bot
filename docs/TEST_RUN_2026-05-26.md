## Release Judgment

Current state is not alpha-ready for real user testing. The browser can reach a valid recommendation safely, but the product cannot complete the draft confirmation path because `/parse` returns 500 during meta collection. The missing free composer on the new chat screen also prevents many intended natural-language entry paths from being used.

Recommended fix order:

1. Prevent partial `application_state.draft` from violating `ReservationFormData` response schema. Either return `draft: null` until all required fields are non-empty, or relax the response shape for partial drafts.
2. Add a free composer to `ChatStarter`, or route new-chat text input through `ChatScene` before example selection.
3. Make `clientIdPlugin` resilient to concurrent first requests. Handle Prisma `P2002` by reading/updating the existing client instead of returning 500.
4. Retest P1 DraftCard through submit-preview boundary, still stopping before final GLS `저장`.
5. Seed completed conversations and retest P2/P3 once draft completion works.
